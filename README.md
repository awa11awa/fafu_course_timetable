# fafu课程表 · Android 应用

#本项目完全由deepseek开发

下载链接：https://github.com/awa11awa/fafu_course_timetable/releases/download/v1.2.3/fafu.-v1.2.3-arm64.apk

福建农林大学正方教务系统课表 App。Flutter 开发，蓝白纯色简约风格。

产物：`../apk/fafu课程表-v1.1.0-arm64.apk`（26.5 MB，arm64，minSdk 24 / targetSdk 36）

---

## 一、功能

| 模块 | 说明 |
| --- | --- |
| 登录 | 学号 + 密码 + 验证码登录正方教务系统（`jwgl.fafu.edu.cn`），账号密码只存本机 |
| 今日课程 | 主页显示今天的课表，含节次、起止时间、地点、教师，并高亮"即将上课"的那一节 |
| 周课表 | 按周查询，可切换周次；提供**课表网格**与**列表**两种视图，表头自动标出今天 |
| 上课提醒 | 两种方式可选：**推送消息**（通知栏，响一声）／**闹钟提醒**（全屏弹出 + 闹钟铃声 + 震动 + 常驻）；可设提前 5/10/15/20/30 分钟 |
| 自动更新 | 后台定时从教务系统重新拉取课表并重排提醒，间隔可选 1/3/6/12/24 小时 |
| 学期设置 | 设置"开学第一周的周一"，用于计算当前是第几周 |

### 界面

- 纯净蓝白配色：主色 `#1565C0`，背景 `#F6F9FD`，卡片纯白
- 底部三个 Tab：今日 / 课表 / 设置
- 卡片式圆角布局，无阴影、无渐变，扁平简约

```bash
adb install -r ../apk/fafu课程表-v1.1.0-arm64.apk
```

或把 APK 传到手机直接点击安装（需允许"安装未知来源应用"）。

首次使用：

1. 打开 App → 输入学号、密码
2. 点验证码图片可刷新，输入图片中的 4 位字符
3. 登录成功即自动抓取课表
4. 到「设置」→「学期」里选一次开学第一周的周一
5. 到「设置」→「上课提醒」选择提醒方式，并按需授权通知/闹钟权限

## 三、关于验证码与自动更新（重要）

正方教务系统的登录**每次都要求输入图形验证码**，服务器端校验，因此 App 无法在后台静默重新登录。实现方式是：

- 登录成功后，把教务系统发放的**会话 ID**（该系统不使用 Cookie，会话 ID 直接写在 URL 里，形如
  `http://jwgl.fafu.edu.cn/(xxxxxxxxxxxxxxxxxxxx)/xskbcx.aspx`）保存到本机
- 后台任务每 15 分钟做一次**轻量保活**请求（访问课表页），使服务器会话不过期
- 到达用户设定的更新间隔时，才真正重新拉取课表并重排提醒
- 若会话仍然过期，App 会发通知提示"登录已过期，请重新登录"，此时打开 App 重新登录一次即可

因此：**建议保持自动更新开启**，保活频率越高，会话存活的概率越大。

## 六、常见问题

**Q：打开是白屏？**

v1.0.0 确实存在这个问题，原因与 App 代码无关：构建时用了 Linux 桌面引擎的
`gen_snapshot` 来生成 Android 的 AOT 快照，产物与 Android 引擎不匹配，引擎拒绝加载
Dart 代码 → 白屏。v1.0.1 已改用 Flutter 专为 Android arm64 目标提供的那份
`gen_snapshot`，根因已修复，详见 `../ARM64构建说明.md` 第 2.2 节。

同时 v1.0.1 也重构了启动流程：`runApp()` 立即执行，通知/后台任务等插件初始化
全部推迟到首帧之后并各自捕获异常。因此即使将来某个环节出错，也**不会再白屏**，
而是显示一个带具体错误信息的"启动失败"页（截图即可反馈）。

安装新版本前请先卸载旧版本（签名虽然相同，但版本号变了，直接覆盖安装也可以）。

**Q：提示「无法连接教务系统」？**

> **v1.0.4 已修复此问题。** 根因有两个，都在客户端代码，与网络无关：
>
> 1. **拿不到会话 ID。** 正方把会话 ID 放在首页 302 跳转的 `Location` 里
>    （`/(会话ID)/default2.aspx`），而 `package:http` 的 `response.request.url`
>    返回的是**原始请求** URL，自动跟随重定向后取不到最终地址 → 会话丢失。
>    现改为**手动跟随重定向**。
> 2. **会话 ID 丢了括号。** URL 必须是 `/(会话ID)/page.aspx` 这种**带圆括号**的形式；
>    用正则捕获组取值时把括号丢掉了，变成 `/会话ID/page.aspx`，服务器找不到会话，
>    返回正方自己的错误页「ERROR - 出错啦！系统正忙！请重新登录」。
>
> 这两个 bug 叠加，表现就是**网络诊断全过、但登录报"无法连接教务系统"**。

若日后仍遇到，按下面排查（登录页有「网络诊断」按钮）：

1. **看接入地址选对没有。** 登录页顶部有「校内直连 / 校外 WebVPN」切换。
   学校公告[《校外访问"教务管理系统"》](https://xxgk.fafu.edu.cn/f9/3a/c5411a325946/page.htm)
   明确说明校外访问要用 **`https://jwgl.webvpn.fafu.edu.cn:880/`**。
2. **点「网络诊断」。** 它会跑一遍真实登录流程，输出：
   会话是否取到、验证码是不是 GIF 图片。若验证码那步显示"不是图片"，
   说明服务器返回了错误页（会话无效或系统繁忙）。
3. **确认自己在校内还是校外。** 校内直连；校外走 WebVPN。

**Q：验证码一直提示错误？**

> **v1.0.5 已修复此问题。** 根因：`submitLogin()` 在提交前又调用了一次
> `openLoginPage()`，而**正方每访问一次首页都会新建一个会话**，验证码只对
> 生成它的那个会话有效。于是用户看到的验证码属于旧会话，提交却发到新会话，
> 必然报"验证码不正确"。
>
> 修复方式：登录页只加载一次，提交时复用同一会话的 `__VIEWSTATE`；
> 登录失败后整体刷新（会话 + VIEWSTATE + 验证码一起换），保证三者始终一致。

若仍遇到：输入图片上的 4 个字符，容易看错（如 `g`/`9`、`a`/`d`）可点图片换一张。
图上字符是随机大小写，**区分大小写**。

### 用学校统一身份认证登录（v1.1.0 起）

登录页最上方新增「**统一身份认证登录**」：内嵌学校真实登录页

```
http://auth.fafu.edu.cn/authserver/login?service=http://ehall.fafu.edu.cn/login
```

流程：

1. 点「统一身份认证登录」，在 App 内完成**滑块 + 短信验证**
   （这两步必须由你自己做，App 不参与，也不会读取你的任何信息）
2. 登录成功后在大厅里打开「**课表**」
3. 看到课程后，点右下角「**导入课表**」
4. App 会把当前页面的课表转成与原来**完全相同的数据结构**并保存

之后**今日 / 课表 / 设置三个页面、上课提醒、自动更新，全部与原来一致**——
换的只是登录与取数入口，界面没有任何改动。

> 说明：该入口的课表是登录后由服务端下发的微应用，App 无法预先知道地址，
> 所以采用"你打开课表页、点导入"的方式，而不是后台静默抓取。
> 若提示"当前页面没读到课表"，请确认上方页面已经显示出课程表格，再点一次导入。

**Q：登录成功但显示「无课程信息」？**

> **v1.0.6 已修复此问题。** 根因在 HTML 解析：`package:html` 按 HTML5 规范解析时，
> 会给 `<table>` **自动补上 `<tbody>`**，于是 `table.children` 拿到的是 `[tbody]`
> 而不是 `[tr, tr, ...]`，导致课表网格为空、解析出 0 门课。
> （Python 版用的 BeautifulSoup+lxml 不会补 tbody，所以同样的写法在那边是好的。）
>
> 修复方式：改用 `table.querySelectorAll('tr')` 取行，并排除嵌套表格里的行。
> 已用真实课表页写了回归测试 `test/parser_test.dart`，可稳定解析出 24 门课。

**Q：「今日课程」写着「共 1 节」但下面一张卡片都没有？**

> **v1.0.7 已修复此问题。** 根因是课程卡片的布局：`Row` 用了
> `CrossAxisAlignment.stretch`（想让左侧蓝色时间条撑满卡片高度），但卡片放在
> `ListView` 里，**高度是无界的**，`stretch` 会要求子项撑到无限高，布局直接抛异常：
>
> ```
> BoxConstraints forces an infinite height.  (h=Infinity)
> RenderFlex._computeSizes / performLayout
> ```
>
> 结果就是数据算对了（"共 N 节"），但卡片一个都渲染不出来。课表页默认用网格视图、
> 不走这个卡片，所以那边正常。
>
> 修复方式：用 `IntrinsicHeight` 先给行定出实际高度，再让子项 stretch。
> 回归测试见 `test/card_test.dart`（已验证：改回旧写法必失败，修复后通过）。

**Q：为什么需要手动选「现在是第几周」？**

正方课表页面里只有学年/学期两个下拉，**没有当前周次信息**，App 无法自动得知。
早期版本"没设置就当作第 1 周"，而很多课从第 2 周才开始，于是「今日」显示为空。
v1.0.7 起：未设置时「今日」页顶部会出现提示条，点一下选「现在是第几周」即可，
之后按周自动顺延。

**Q：后台自动更新没有生效？**

见上文第三节。另外请在系统设置里允许「fafu课程表」自启动/后台运行，
并把电池优化设为"不限制"，否则 WorkManager 可能被系统冻结。

## 七、已知限制

- **仅提供 arm64 包**：32 位 ARM 的 AOT 编译需要 `gen_snapshot` 识别
  `sim_use_hardfp` 等 VM flag，而 arm64 宿主版引擎不提供，故只出 arm64。
  近年手机均为 arm64，正常使用无影响。
- **图标未裁剪**：构建使用 `--no-tree-shake-icons`，APK 因此略大约 1 MB。
- **验证码需手动输入**：见上文第三节。
- 作息时间（第 N 节的起止时刻）写在 `lib/theme.dart` 的 `PeriodTime` 中，
  若与学校实际作息不符，改这里即可。
