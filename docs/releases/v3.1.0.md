## FAFU课程表 v3.1.0

正式版 APK、完整源码和 main 分支对应同一提交。

- 修正课程时间：1–2节为 08:00–09:35，3–4节为 09:55–11:30，6–7节为 14:00–15:35（仓山校区）。同步时读取并保存学校作息配置，其他校区使用对应配置。
- 课表显示与课前提醒共用学校时间，提醒按中国标准时间计算；已保存的作息在重新启动后仍可用。
- 补齐 Android 定时通知及开机、更新后恢复接收器，修复提醒无法触发的问题。
- 设置页新增提醒权限状态、检查权限和10秒后测试提醒。未允许准时提醒时使用可能延迟的系统提醒；全屏提醒需允许全屏权限。
- 确认学校登录失效时发送通知，同一次失效只提醒一次；重新登录并同步成功后可再次提醒。关闭上课提醒不影响登录失效通知。网络异常不会误报登录失效，也不会删除缓存课表。
- 设置页底部和安装包版本统一为 v3.1.0（versionCode 30100）。修正构建依赖源，避免原镜像服务异常造成构建失败。
- 保留启动和返回前台时恢复学校会话并同步的功能；学校会话本身失效仍需重新登录。

安装后到「设置 → 上课提醒」检查并允许通知及准时提醒权限，然后点击「10秒后测试提醒」并返回桌面验证。系统“强行停止”应用后，需要先重新打开应用，系统才会恢复允许提醒运行。

`FAFU-v3.1.0.apk` 使用正式包名 `cn.fafu.fafu_kebiao`。当前仓库没有生产签名密钥，按现有构建配置使用 CI 签名；如果旧版本提示签名冲突，先保留课表和会话，再卸载旧正式版安装。v3.0.0 测试版使用独立包名，可以共存，但本地数据不会自动跨应用迁移。

附件包含 `FAFU-v3.1.0.apk`、`fafu_course_timetable-v3.1.0-source.zip`、`BUILD_INFO.json` 和 `SHA256SUMS`。完整源码已还原图标及 Gradle wrapper，不包含账号密码、抓包记录或学校会话。自动回归测试及编译检查不代替手机实际提醒验证。
