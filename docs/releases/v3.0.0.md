## FAFU课程表 v3.0.0 测试版

这次测试的重点是：杀掉应用后，下次打开能恢复已保存的学校会话并同步课表。

- 保存学校 CAS 和课表网关会话，网关或课表令牌失效时尝试重新获取。
- 启动和回到前台时自动同步；短时间重复切换前台会合并请求。
- 网络失败时保留本地课表；学校会话失效时提示重新登录。
- 支持在自己的手机上导入保存的学校会话，并由应用登录 WebView 保存会话。
- 使用独立包名 `cn.fafu.fafu_kebiao.v3test`，应用名称为「FAFU v3 测试版」，可与正式版及旧测试版同时安装。

### 安装与测试

1. 下载并安装 `FAFU-v3.0.0-test.apk`。
2. 在设置中完成统一身份认证登录，或导入手机本地保存的学校会话。
3. 按应用提示开启 HTTP 认证恢复，并确认「自动同步课表」已开启。
4. 完成一次同步后杀掉测试应用，再次打开，检查「上次同步」时间及课表。

独立测试版需要重新登录或导入会话，不会读取数字 FAFU 或其他应用的私有会话。
学校 CAS 会话自身失效后仍需重新登录；此版本不承诺永久登录，也不依赖持续心跳实现重新打开后的同步。
已经运行自动测试和构建检查，真实手机的登录流程与长期会话有效期仍需要实际使用验证。

### 附件

- `FAFU-v3.0.0-test.apk`：版本 3.0.0，versionCode 30000 的 Android 测试安装包。
- `fafu_course_timetable-v3.0.0-source.zip`：与 APK 同一提交的完整源码，已还原图标与 Gradle wrapper。
- `BUILD_INFO.json`：构建提交、包名、Flutter 版本、构建运行链接与附件校验信息。
- `SHA256SUMS`：附件 SHA-256 校验值。

源码使用 Flutter 3.47.6 / JDK 17；执行 `flutter pub get` 后，使用
`FAFU_SESSION_TEST=true flutter build apk --release` 构建测试包。
测试包使用 CI 调试密钥签名，后续新构建若签名不同，可能需要卸载旧测试版后安装。
